# 📰 Tech Insights Blog

A modern, responsive **Tech Blog landing page** built with **HTML & CSS**.  
This project shares the latest trends in technology with clean sections, impactful visuals, and a fully responsive layout.

---

## 📚 **Description**

This project features:
- A sleek header with navigation links
- An eye-catching hero section with a headline and intro
- Two featured blog sections: *The Impact of 5G* and *The Ethics of AI*
- Visually balanced content with text and images
- Fully mobile-friendly, responsive design

---

## ⚙️ **Features**

- **Fixed Header & Smooth Layout**
- **Hero Section** with overlay and call-to-action text
- **Content Sections** with side-by-side text and images
- **Modern Typography** using custom fonts
- **Responsive Design** for desktop, tablet, and mobile screens

---

## 🛠️ **Technologies Used**

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Custom Web Fonts (Kumbh Sans)

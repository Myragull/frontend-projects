# 🧱 Responsive Layouts – No Struggle

A modern, responsive web layout built with **HTML** and **CSS** as part of a 21-day responsive design challenge.  

## 📜 Description

This responsive layout project demonstrates how to build a structured, fully responsive web page without using any JavaScript.  
The layout includes multiple sections such as:

- A responsive header with navigation and CTA buttons  
- A hero section with split content  
- A three-column features grid  
- An info section with text and image blocks  
- A flexible footer with four columns

## ✨ Features

- ✅ Fully responsive design (mobile-first)
- ✅ Clean and semantic HTML structure
- ✅ Modern CSS styling with media queries
- ✅ Custom fonts via Google Fonts

# ⏰Dark/Light Mode Digital Clock

A clean, modern **Digital Clock** built with **HTML, CSS, and JavaScript**.  
This project displays the current time in real-time with a stylish UI and includes a **Dark/Light Mode toggle** that remembers your preference.

---

## 🕒 **Description**

This project features:
- Real-time clock display using JavaScript
- Glassmorphic clock container with clean typography
- **Dark & Light Mode** with a toggle button
- Theme preference saved in `localStorage`

---

## ⚙️ **Features**

- **Live Updating Clock:** shows the current time in `HH:MM:SS` format
- **Theme Toggle:** switch between Dark and Light Mode with one click
- **Persistent Theme:** saves your preference even after you refresh or revisit
- **Glassmorphism & Shadows:** clean modern design elements

---

## 🛠️ **Technologies Used**

- HTML5
- CSS3 (Flexbox, backdrop-filter, custom dark/light theme)
- JavaScript (Date API, DOM manipulation, `localStorage`)
